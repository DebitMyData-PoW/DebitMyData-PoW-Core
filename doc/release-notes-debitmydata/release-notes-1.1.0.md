# DebitMyData PoW Core v1.1.0

We are pleased to announce the release of **DebitMyData PoW Core v1.1.0**, bringing our blockchain software in line with the latest DebitMyData Core v1.1.0 architecture and improvements.

This release focuses on maintaining long-term compatibility with upstream DebitMyData development while introducing numerous performance, networking, stability, and infrastructure enhancements inherited from DebitMyData Core 31.0.



### Highlights

* Upgraded codebase to align with DebitMyData Core v1.1.0
* Improved node performance and resource management
* Enhanced peer-to-peer networking reliability
* Updated mempool and transaction handling improvements
* Various RPC and backend infrastructure updates
* Additional bug fixes and stability enhancements
* Improved synchronization and blockchain validation performance
* Security and maintenance updates inherited from upstream DebitMyData development



### Notes

This release does **not** introduce any consensus rule changes and does not require a blockchain fork. Existing wallets, addresses, and blockchain data remain fully compatible.

Node operators, mining pools, exchanges, block explorers, and service providers are encouraged to upgrade to benefit from the latest performance, networking, and stability improvements.

As always, thank you for supporting DebitMyData and helping strengthen the network.
