\# DebitMyData Core v1.2.1



\## Overview



This optional maintenance release improves the user experience following the mandatory v1.2.0 consensus update.



\## What's Changed



\- Suppressed the expected "Found invalid chain more than 6 blocks longer than our best chain" warning when the node intentionally rejects the old fork protected by the mandatory chain anchor.

\- No consensus changes.

\- No wallet or blockchain compatibility changes.



\## Upgrade Notes



This update is \*\*optional\*\*.



Users already running \*\*v1.2.0\*\* are fully synchronized with the official blockchain. v1.2.1 simply removes an expected warning message that could appear during synchronization.
