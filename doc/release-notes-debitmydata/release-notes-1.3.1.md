\# DebitMyData Core v1.3.1



This release includes minor wallet improvements and updates the chain parameters now that the network has fully converged on the correct blockchain.



\### Changes



\* Updated wallet display units:



&#x20; \* µDMD (bits) → µDMD (debits)

&#x20; \* Satoshi (sat) → nDMD (data)

\* Updated `assumevalid`.

\* Updated `nMinimumChainWork`.

\* Updated `chainTxData`.

\* Updated `m\_headers\_sync\_params` for the current network state.



\### Compatibility



\* No consensus changes.

\* No blockchain reindex required.

\* Existing wallets remain fully compatible.



\### Upgrade



Updating is recommended to benefit from the latest wallet improvements and updated chain synchronization parameters.
